Git Nedir?

Git dağıtık süremleri kontrol etmek için kullanılır ,versiyonları kontrol etmek yazılım geliştirme süreçlerini kolaylaştırmak için kullanılır.
-------------
"git pull" ile "git fetch" komutlarının farkı nedir?

git fetch : Uzaktaki repodaki verileri kendi localimize indirir 
git pull : git fetch + git merge . Hem verileri indiri hemde projemize gerekli dosyaları ve değişiklikleri indir.
-------------
Eğer takım arkadaşımız "kodlarımı gönderdim, benim geliştirmemin üzerine devam et" derse ve gönderdiği kodları "git pull" ile lokalimize alamıyorsak nerelerde hata yapılmış olabilir?

merge conflickte olabilir.
-------------
"git fetch origin" komutundaki "origin" neye karşılık gelmektedir?

uzak repodaki adresin adı.
-------------
"HEAD" kelimesi neyi temsil etmektedir?

şuan üstüne çalıştığımız commiti ifade etmektedir
-------------
"Staging Area" ya da "Index" diye isimlendirilen bölge tam olarak ne demektir?

Staging Area : yaptığımız değişiklikleri tuttuğumuz ara alan.
--------------
"Untracked file" ne demektir?

git tarafından takip edilmeyen dosyalar denir.
--------------
".git" klasörünü silersek ne olur?

git klasörü meta verileri içeiri ve artık versiyon kontrolü yapamayız.
-------------
Kendi lokalimizde her "git init" komutunu kullanıdığımızda otomatik olarak "ReadMe.md" dosyası oluşturulmasını istiyorsak ne yapmalıyız?

kendi templatize ReadMe yi tanımlarsak bundan sonra her çağırdımızda gelir.
-------------
Git konusunda bahsi geçen "branch" yapısı nedir? Bize ne sağlar?

branch dallanmadır geliştreceğimi projeleri farkı alanlarda geliştirer karşılıkliği engeller. Birden çok yazılımcını paralel olarak çalışmasını sağlar.
-------------

-------------
Sıfırdan bir "branch" nasıl oluşturabiliriz?

-------------
 "git clone" komutunu kullanırken belirli bir spesifik branch'i sadece çekmek istiyorsak nasıl yapabiliriz?
